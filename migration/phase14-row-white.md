# Phase 14 — 列表行白色高亮

- 日期：2026-10-18
- 触发：用户接着上一轮说"再将列表视图的文件或者网址像表格视图一样白色高亮显示"
- 范围：只改列表行的默认底色

---

## 1. 变更

Phase 13 把列表的白色外框去掉后，行和页面共用同一底色，虽然和网格的"页面底色"一致，但行本身不再突出。
Phase 14 把**行恢复成白色卡片条**（`scheme.surfaceContainerLowest`），页面底色仍是 `scheme.surface`：

| 部分 | 底色 |
|---|---|
| 页面 / 表头 / 列表下方空白 | `surface`（浅灰蓝） |
| 普通数据行 | `surfaceContainerLowest`（白） |
| 行 hover | 白色上叠加 `primary` 5% 淡染（不透明混合，Material 上仍能显示水波） |
| 选中行 | `primaryContainer` |
| 路径缺失行 | `missingRowTint`（红色淡底） |

- 表头保持 Phase 13 的"页面底色 + 底部发丝线"，不再是一整块白面板；
- 行之间仍是 `outlineVariant` 发丝分隔线，没有加间距/圆角（保持表格的紧凑阅读节奏）；
- 拖拽排序、选中、右键、双击、空态等行为不变。

效果：文件/网址行在浅灰蓝页面上以白色条高亮，和网格视图的白色卡片形成同一套"内容白色、页面有色"的视觉语言，
但不会回到 Phase 13 之前"整张表都是白板"的状态。

## 3. 可再调

- 如果觉得白条太"满"，可以把每行左右各留 8px、加 6px 圆角和 2px 垂直间距，做成"卡片条"；
- 或者只给 hover/选中白，普通行保持页面底色——说一声即可切换。
