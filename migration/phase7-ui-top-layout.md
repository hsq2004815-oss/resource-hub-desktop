# Phase 7 — 顶部布局重构（Material 3）

- 日期：2026-10-18
- 触发：用户提供参考稿（Clean Chinese Resource Manager Dashboard）并指出原顶部布局"AI 感重"
- 范围：**只改布局与呈现**；`backend/` 零改动，`folders.json` 格式、CRUD、搜索、收藏、分类、路径选择、打开/定位、拖拽、导入导出、热键、设置全部保持原行为

---

## 1. 问题

原顶部是"落地页"结构：浅蓝色 hero 带 + 大标题 + 长副标题 + 4 个功能胶囊 + 3 张统计卡 + 语言/主题快捷开关，下面再是常驻左表单 + 右列表。结果：

- 顶部与主体大面积色差，层级靠"色块/卡片/阴影"堆出来，M3 的中性表面语义被打破；
- 顶部约 280px、列表头再约 150px，资源列表实际可用高度被挤压；
- 「新增资源」常驻占 340px 宽，压缩了表格；
- 主色（蓝）被统计卡图标、chip、分类胶囊到处使用，失去"主操作"指向性。

## 2. 新结构

```
┌──────────────────────────────────────────────────────────────┐
│ AppTopBar 56px：图标 + 短标题                              ⚙设置 │  ← 与主体同 surface，仅底部分割线
├──────────────────────────────────────────────────────────────┤
│ 已保存资源 (3)  当前显示 3 / 3      [网站|资源] [列表|网格] [+ 添加资源] │
│ [搜索…………………………] [全部分类▾] [只看收藏] [打开][收藏][检测][导出][导入][编辑][删除] │
│ ┌──────────────────────────────────────────────────────────┐ │
│ │ 列表（表格）或 网格（卡片）                                │ │
│ └──────────────────────────────────────────────────────────┘ │
├──────────────────────────────────────────────────────────────┤
│ 状态栏：轻量文本，与主体同 surface，仅顶部分割线                    │
└──────────────────────────────────────────────────────────────┘
```

- **AppTopBar**（`features/home/app_top_bar.dart`，56px）：应用图标 + `window_title` 短标题 + 设置入口；没有描述、胶囊、统计卡、语言/主题快捷开关（语言/主题回到设置对话框，与旧版一致）。
- **工作区头部**（`features/home/resource_list_panel.dart`）：标题 + `(总数)` + 汇总文案是**轻量辅助文本**；右侧是模式切换（网站/资源）、列表/网格切换、**唯一的填充主按钮「添加资源」**。
- **第二行**：搜索框（自适应宽度）、分类下拉、只看收藏、选择项操作（打开/收藏/检测/导出/导入/编辑/删除）。
- **内容区**：列表（原表格）或网格（新增卡片视图），两者共用选中/双击打开/右键菜单行为。
- **左表单改为对话框**：`ResourceForm` 原样复用（新增可选 `onClose`），「添加资源」与「编辑」都打开它；保存成功关闭，校验/重复错误保持打开并显示在状态栏。

## 3. 实现要点

| 要求 | 落地 |
|---|---|
| 顶部与主体同色、仅细分割线 | `AppTopBar` 使用 `ColorScheme.surface`；`scaffoldBackgroundColor` 也是 `surface`；状态栏从 `surfaceContainerLow` 改为 `surface`，只保留 `outlineVariant` 顶边框；hero 色块/渐变/阴影全部移除 |
| 顶部压缩到 48–56px | `AppTopBar.height = 56`；窗口原生标题栏保留 |
| 搜索/筛选/视图切换/主操作进入工作区顶部 | `ResourceListPanel` 第一、二行 |
| 主色只用于主操作/选中/焦点 | 新增按钮用 `FilledButton`；分类胶囊由 `primary` 改为中性 `onSurfaceVariant + surfaceContainerHigh`；表格外框圆角 `lg → md` |
| 不改业务逻辑 | 所有数据操作仍走 `ResourceApi`；`_persistDraft` 只是原 `_handleSubmit` 的拆分；后端/协议/JSON 未动 |

新增文件：

- `lib/features/home/app_top_bar.dart`
- `lib/widgets/resource_grid.dart`（`ResourceLayout` 枚举 + 网格卡片视图）
- `lib/widgets/resource_table.dart`：抽出 `showResourceContextMenu`，表格与网格共用同一右键菜单
- `lib/features/home/resource_form.dart`：新增可选 `onClose`（对话框关闭按钮）

删除：`lib/features/home/header_bar.dart`（hero/统计卡/胶囊/快捷开关）。

## 4. 验证

| 项 | 结果 |
|---|---|
| `flutter analyze` | 0 issue |
| Flutter 测试 | **32 / 32**（22 外壳 + 7 协议 + 3 JSON 备份） |
| 新增测试 | 顶栏紧凑/无统计卡与 hero、添加按钮打开对话框、列表↔网格切换；语言/主题测试改为走设置对话框 |

| 实机 | light / dark / English 截图；窗口缩放到最小尺寸；关闭→托盘、热键、拖拽、打开/定位、导入导出回归通过（`verify_shell.py` 9/9） |

实机截图：`migration/screenshots/phase7-top-light.png`、`phase7-top-dark-en.png`、`phase7-top-min.png`、`phase7-top-app.png`。

**打包注意**：Flutter release 默认 `--tree-shake-icons` 只会保留 const 上下文的 `IconData`，本页新增的
列表/网格与导出/导入图标是通过 widget 参数传入的，会被漏掉（按钮空白）。`build-flutter-release.ps1`
已改为 `flutter build windows --release --no-tree-shake-icons`：字体 6 KB → 1.6 MB，发布包 46.1 → **47.7 MB**。
