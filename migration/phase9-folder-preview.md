# Phase 9 — 文件夹预览面板（Mind Map）

- 日期：2026-10-18
- 触发：用户发现"单击资源行没有效果"，提议从右侧弹出二级界面，以树状/脑图形式展示文件夹里的内容，并提供了
  NotebookLM Mind Map 参考图（保存在 `migration/screenshots/phase9-mindmap-reference.png`）
- 范围：新增右侧详情面板 + mind map 交互；后端只新增**只读**的文件系统浏览方法，资源数据格式和业务逻辑不变

---

## 1. 与用户确认的设计

| 议题 | 结论 |
|---|---|
| 面板形态 | **非模态**右侧浮层，遮住列表右侧，不压暗/不阻塞工具栏与拖拽 |
| 打开方式 | **单击任意资源行**打开并跟随选中切换；`Esc` / × / **点击面板外任意区域**关闭 |
| 面板宽度 | 默认 **560**，左边缘可拖动调整（420–760，窗口不足时自动收紧），宽度只在本次会话记住 |
| 文件夹内容 | 横向 **mind map**：根节点 = 资源本身；单击根打开时只展开第一层 |
| 展开方式 | 文件夹节点右侧 hover 出现圆形 `›`，点一下**只读一层**并展开；展开后按钮常显并旋转为 `‹`；文件是叶子节点、无按钮 |
| 节点交互 | 单击=选中（底部显示完整路径 + 复制）；双击=资源管理器打开；右键菜单含"添加为资源" |
| 缩放/平移 | `Ctrl+滚轮` 以指针为中心缩放 40–200%；滚轮平移；`Shift+滚轮` 横向；拖空白平移；双击空白/「适应」按钮复位；面板工具条有 `－ / 百分比 / ＋ / 适应`，并显示快捷键提示 |
| 按钮可见性 | hover / 选中 / 键盘焦点时显示，展开状态常显（兼顾可访问性） |
| 其他资源 | 网站行显示链接信息 + 操作；文件行显示文件信息 + 打开位置；两者都不画 map |

## 2. 布局位置

面板放在**工作区内容区**（`ResourceListPanel` 的列表/网格区域）内部，而不是整个页面：

- Phase 7 的「添加资源 / 网站·资源 / 列表·网格 / 搜索 / 分类 / 工具栏」全部保持可点，
  不会被面板盖住（初版曾按整页浮层实现，工具栏被遮住，已修正）；
- 面板只在列表内容区从右侧滑入，视觉上是"遮住一部分应用界面"，但顶部控件仍可用。

## 3. Mind map 实现

`app/lib/widgets/mind_map.dart`：

- 自研横向 tidy tree 布局：节点宽度按文本测量（上限 226 / 根 280），根垂直居中、子节点纵向排列、
  贝塞尔曲线连接（`CustomPainter` 画在节点下层）；
- **懒加载**：每个节点展开时才调用一次 `fs.children`，结果缓存在本次面板会话里；空文件夹显示"空文件夹"、
  读取中显示 spinner、失败显示错误节点（可点击重试）、超过 200 项显示"还有 N 项未显示"；
- 圆形展开按钮是独立 overlay（与节点同层、位于右边缘），因此 hover/选中/焦点都能正常命中；
- 画布用 `Transform` 做缩放/平移；背景手势与节点手势分离（背景双击复位不会给节点单击增加 300ms 延迟）；
- 键盘：`↑/↓` 遍历可见节点、`→` 展开/进入子节点、`←` 收起/回父节点、`Enter` 打开、`+/-/0` 缩放；
- 防无限展开：深度上限 12 层（junction 循环最坏也会被截断）；
- 右键菜单：打开 / 在资源管理器中显示 / 复制路径 / **添加为资源**。

`app/lib/features/home/resource_detail_panel.dart`：

- 非模态侧栏：`surfaceContainerLow`、左侧 16px 圆角、发丝边框、轻阴影；进入时 180ms 滑入；
- 头部：图标 + 名称 + 「类型 · 分类」；路径行（tooltip + 复制）；操作行（打开 / 在资源管理器中显示 / 编辑 / 收藏）；
- 文件夹主体 = mind map + 缩放工具条；链接/文件主体 = 信息行 + 快捷按钮；
- 左边缘 8px 拖动条调整宽度；底部显示选中节点路径（点击可复制）。

## 4. 后端 / 协议

新增只读方法（不动 `service` 业务层）：

```
→ {"id": 9, "method": "fs.children", "params": {"path": "D:\\Books"}}
← {"id": 9, "ok": true, "result": {
     "path": "D:\\Books",
     "entries": [{"name": "Design", "path": "D:\\Books\\Design", "kind": "folder", "isLink": false}, ...],
     "total": 42, "shown": 42, "truncated": false}}

→ {"id": 10, "method": "fs.open",   "params": {"path": "D:\\Books\\Design"}}
→ {"id": 11, "method": "fs.reveal", "params": {"path": "D:\\Books\\Design"}}
```

- 单层读取、目录在前按名称（casefold）排序；最多返回 200 项，但统计整个目录（最多扫描 2000 项）以便显示剩余数量；
- 缺失路径 / 不是目录 / 拒绝访问 / 无法读取 → `operation_failed` + i18n key（`fs_not_found` 等），
  面板内联显示并可重试，不影响主界面；
- junction/symlink 用 `isLink` 标记，在节点上显示小链接图标；
- `fs.open` / `fs.reveal` 复用现有 launcher，native runner 可用时优先走 runner（前台窗口交接正确），
  失败再回退到后端；
- 新增 `backend/resource_hub_core/fs.py`；`protocol.py` 注册 3 个 handler；其余文件未改。

## 5. UI 接线

- 表格/网格新增 `onPreview` 回调：**单击（tap）** 打开面板；拖动手柄、右键、双击行为不变；
- 面板外层包 `TapRegion(onTapOutside: ...)`：**点击面板外任意位置都会关闭**（空白处、工具栏、状态栏、
  其他行都算）；如果点的是另一行，行的 `onPreview` 会紧接着用新内容重新打开，视觉上等于"切换详情"；
  面板内部点击不会关闭。`Esc` / × 保留；
- `HomePage` 维护 `_detailOpen` / `_detailWidth`；`ResourceListPanel` 新增 `detailsPanel` 槽位，把面板放在内容区右侧；
- 「添加为资源」直接调用现有 `resources.add`（folders 数据集，默认未分类），成功后切到资源标签、
  刷新列表、选中新资源并保持面板打开；重复路径走原有重复错误提示；
- 新 UI 文案全部在 `app_strings_ext.dart`（`strings.g.dart` 未动）。

## 7. 实机验证

- 发布包 **47.9 MB** 合并进 `release\ResourceHub-Desktop-20261017-1835\`，用户数据保留
  （合并前后 `folders.json` / `sites.json` 哈希一致，用户自己拖出的顺序不变）。
- 单击 "Desktop" 行 → 右侧面板从内容区滑入，mind map 自动 fit（66%），根节点 + 16 个子项
  （文件夹/文件带不同图标）全部可见；面板不遮挡顶部工具栏 —— `phase9-panel.png`。
- 悬停 "Hubstudio" → 右侧圆形 `›` 出现（`phase9-hover.png`）；点击后只加载这一层，
  出现第三级 "千库测试" 与曲线连接，按钮旋转为 `‹` —— `phase9-expanded.png`。
- `Ctrl+滚轮` 在画布上缩放：66% → 200%（上限），工具条百分比同步更新 —— `phase9-zoom.png`。
- `verify_shell.py` **9/9 PASS**（关窗→托盘、全局热键、二次启动唤醒、WM_DROPFILES 子窗口拖入）。
- 面板关闭后主界面状态不变；应用以新版本在桌面运行（`phase9-app.png`）。
- **点击面板外空白处关闭**：实机点击列表下方空白区域，面板立即消失；点击面板内部（如标题）保持打开。

> 实机发现并修复的问题：① 初版面板是整页浮层，会盖住顶部工具栏 → 改为只放在内容区；
> ② mind map 初版在 Column 里 shrink-wrap，fit 偏移把根节点裁掉 → Column 改 `stretch` 撑满宽度；
> ③ 首次 fit 跑在 loading 占位阶段 → 根节点数据返回后补一次 fit；
> ④ hover 按钮位于节点边界，鼠标移上去先触发节点 `onExit` 导致按钮消失 → 增加 `_toggleHoverKey`，
> 按钮自身 hover 也保持可见。

## 8. 已知取舍 / 未做

- 面板宽度、展开状态、缩放只在本次会话保留，不写 `settings.json`；
- 文件/网站资源只显示信息面板，不画 map；文件夹资源才有 mind map；
- junction 循环靠深度上限 12 兜底，未做完整的 realpath 祖先检测；
- mind map 节点不支持拖拽调整顺序（排序仍走列表/网格的拖动手柄）；
- 未做节点搜索/过滤、书签、多选；
- 面板只覆盖内容区，因此窗口非常窄时（最小 1180）列表露出宽度约 560，仍可用。
