# Phase 11 — 工具栏精简（导出/导入移入「更多」菜单）

- 日期：2026-10-18
- 触发：用户截图导出/导入两个图标并反馈"这两没啥用吧 删了吧"
- 范围：只改工具栏入口；导入/导出功能本身保留

---

## 1. 变更

- 从第二行工具栏的 `_Toolbar` 中删除两个独立按钮：
  `file_download_outlined`（导出）、`file_upload_outlined`（导入）。
- 功能不删除，移动到同一行的 `⋮`（更多操作）菜单里：

```
⋮
├─ 按添加时间排序
├─ ─────────────
├─ 导出
└─ 导入
```

- 菜单项复用原 `onExport` / `onImport` 回调（仍是原来的 JSON 备份对话框），没有新增业务逻辑。
- 工具栏现在只剩：打开、收藏、检测路径、编辑、删除 + `⋮` + 设置齿轮，右侧更干净，搜索框能拿到更多宽度。

## 2. 验证

| 项 | 结果 |

| `flutter analyze` | 0 issue |
| Flutter 测试 | **50 / 50**（原"工具栏暴露导出/导入"测试改写为：工具栏不再有这两个 tooltip，打开 `⋮` 菜单能看到「导出 / 导入」） |
| 最小窗口 1180×760 | 无溢出（工具栏更短） |

截图：`phase11-toolbar.png`（精简后的工具栏）、`phase11-menu.png`（更多菜单里的导出/导入）。

## 3. 取舍

- 导出/导入只是入口变深，不是删除；如果确认完全不需要 JSON 备份，可以再删掉菜单项、`_exportCollection` /
  `_importCollection` 以及后端 `resources.export/import`（目前保留是为了数据迁移和回滚）。
- `⋮` 菜单现在同时承载排序和备份两个低频操作，符合"低频进菜单"的 Material 3 习惯。
